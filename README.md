# SIMPLE CHAT BOT WITH GROQ AND TELEGRAM

# SOBRE O PROJETO

    Este projeto tem o objetivo de integrar a API do Groq junto com a do Telegram em Python, assim criando um chat bot simples

# COMO RODAR

    Primeiro insira as libs com o "pip install -r requirements.txt"
    Configure suas chaves de API no arquivo .env.
    NÃO compartilhe suas chaves de API com ninguém e nunca as publique no GitHub.
    Acesse o Bot pelo telegram e ai será possivel conversar com ele por um tempo determinado.

# RECADO SIMPLES

    Reitero que este projeto é apenas para estudo e não está pronto para colocá-lo em produção

# TECNOLOGIAS UTILIZADAS

    Python
    Groq APi
    Telegram Bot API
    PyTelegramBotAPI
    python-dotenv
